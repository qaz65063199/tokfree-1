# TokFree 私域运营方案

> 目标：把对 TokFree 感兴趣的用户沉淀到私域（微信 / QQ），持续互动、增强亲密度，并用合理门槛筛选出愿付费支持的用户。
> 原则：**先给价值、再谈变现**；私域是"关系"，不是"广告位"。

## 1. 私域载体选择

| 载体 | 优势 | 劣势 | 适合场景 | 推荐度 |
|------|------|------|----------|--------|
| **QQ 群** | 免审核、容量大（2000人）、文件/群公告强、适合开发者、自动化 bot 友好 | 活跃度偏低、年轻化、部分人少用 QQ | 早期种子用户、内测群、技术答疑 | ⭐⭐⭐⭐⭐ |
| **微信群** | 打开率高、触达强、社交属性强 | 200 人需换群、无文件沉淀、易被封 | 核心用户、付费支持者、高频互动 | ⭐⭐⭐⭐ |
| **企业微信** | 可加好友 1v1、群发合规、可挂客服、可沉淀客户 | 需企业认证、有成本、略"官方" | 中后期变现、1v1 服务、客服 | ⭐⭐⭐ |
| **知识星球** | 内容沉淀强、付费门槛天然、可分栏 | 需付费开通、抽成、用户需注册 | 付费社群、专栏内容、抢先版 | ⭐⭐⭐⭐ |

**推荐组合**：
- 起步：**QQ 群（大群，拉新 + 答疑）+ 微信群（核心活跃）** 双轨。
- 成长：加 **知识星球** 承载付费内容，**企业微信** 做 1v1 服务。

## 2. 拉新路径与引导话术

### 引流渠道
1. **GitHub README**：顶部/底部加"交流群"入口（徽章或文字 + 二维码图）。
2. **视频**：抖音/B站/YouTube 视频结尾口播 + 简介置顶二维码；评论区置顶。
3. **官网 / 落地页**：页脚放"加入交流群"，弹窗引导。
4. **公众号 / 知乎 / 掘金**：文章末尾"回复关键词进群"。

### 引导话术（分层）
- 普通吸引："TokFree 使用答疑 / 更新通知都在群里，扫码进群，有问题随时问。"
- 强价值："群里优先发新版抢先体验包 + 需求投票权，扫这个码。"
- 付费引导（后期）："想支持项目 / 要抢先版 / 要 1v1 指导的，进这个支持者群。"

### 关键动作
- 二维码**定期更换**（微信群 7 天失效）。
- 入口尽量**少而显眼**，不要铺满；一个主入口 + 一个付费入口即可。

## 3. 分层运营

用"**漏斗 + 升级路径**"分三层：

| 层级 | 名称 | 准入门槛 | 主要权益 | 载体 |
|------|------|----------|----------|------|
| L1 | 普通用户群 | 免费进群 | 更新通知、基础答疑、使用交流 | QQ 大群 |
| L2 | 活跃用户群 | 发言/贡献达标（如提过 issue、发过使用帖、邀请 3 人） | 需求投票、内测资格、优先答疑 | 微信群 |
| L3 | 付费支持者群 | 付费（赞助/星友/定制） | 抢先版、1v1 指导、定制需求优先、署名致谢 | 微信群 / 知识星球 |

**升级机制**：
- L1 → L2：主动邀请活跃用户，或用户自荐（发一条"我做了什么"）。
- L2 → L3：公开付费入口，自愿升级，不强制。
- 降级：长期潜水不踢人（避免伤感情），但 L3 到期未续费可回 L2。

## 4. 提高互动与亲密度

- **更新通知**：每次发版在群里@全员（慎用，改为"发版公告 + 置顶"），附更新点。
- **需求投票**：用问卷/投票决定下个版本优先级，让用户有"参与感"。
- **内测资格**：新功能先给活跃/付费群试用，收反馈再放公开版。
- **定期答疑**：每周固定时间"在线答疑"，形成期待。
- **晒使用场景**：鼓励用户晒"用 TokFree 做了什么"，优秀案例群内展示 + 官网收录。
- **铁粉激励**：贡献者名单、专属称号、免费抢先版、周边（可选）。
- **1v1 触达**：对核心用户偶尔私聊，问用得怎么样、有什么痛点（亲密度关键）。

**节奏建议**：每周 1 次公告 + 1 次答疑 + 若干日常闲聊，避免刷屏。

## 5. 付费门槛设计

### 筛选愿付费用户的方式
- **捐赠 / 赞助**：自愿打赏，附"支持者"身份标识。
- **知识星球 / 会员**：付费进圈，享持续内容与答疑。
- **抢先版**：付费用户提前拿到新版。
- **定制服务**：企业/个人定制功能，按需报价。
- **1v1 私教 / 陪跑**：手把手教部署、接入自己项目。

### 定价与权益设计（参考，按实际调整）

| 档位 | 价格（参考） | 权益 |
|------|--------------|------|
| 赞助者 | 任意金额 | 支持者名单署名、群内标识 |
| 月/年费会员 | ¥29/月、¥199/年 | 抢先版 + 1v1 答疑 + 需求优先 |
| 定制服务 | ¥xxx 起 | 按需定制、专属支持 |
| 企业授权 | 面谈 | 商用授权 + 技术支持 |

**设计要点**：
- 门槛不要过高（首档 20-30 元/月为宜），让多数人"够得着"。
- 权益要**具体可感**（抢先版、1v1、优先需求），不要空泛承诺。
- **免费版必须依然可用**，付费是"加速/优先/额外"，不是"阉割"。

## 6. 风险与合规提示

- **避免诱导**：不要承诺收益、不要"付费才能用核心功能"式逼单。
- **避免过度承诺**：不承诺"一定实现某功能""永远免费更新"等无法保证的话。
- **避免过度商业化伤社区**：免费群不要频繁发广告；付费群也要有价值输出。
- **合规**：收付款走正规渠道（微信支付/支付宝/知识星球），保留凭证；涉及商用授权需明确协议。
- **版权**：TokFree 基于 GPL-3.0，衍生与分发须遵守许可，**不得闭源收费分发**（可收服务费/赞助费，但代码须开源）。
- **隐私**：收集用户信息（如加群）需告知用途，不滥用。

## 7. 落地节奏（三阶段）

### 阶段一 · 验证期（0-1 个月）
- 建 1 个 QQ 大群 + 1 个核心微信群。
- 在 README / 视频 / 官网放二维码。
- 目标：**拉到 100-300 人**，验证内容是否有人感兴趣。
- 动作：高频答疑、收集需求、观察谁最活跃。

### 阶段二 · 成长期（1-3 个月）
- 分出活跃群，启动需求投票 + 内测。
- 试水知识星球 / 会员（低门槛）。
- 目标：**沉淀 30-50 名活跃用户、10-20 名付费支持者**。
- 动作：案例征集、铁粉激励、1v1 触达。

### 阶段三 · 变现期（3 个月+）
- 正式上付费体系（会员 + 定制 + 企业授权）。
- 企业微信 1v1 服务；拓展 B 端。
- 目标：**付费用户稳定增长，形成正向循环**。
- 动作：持续内容输出、版本节奏稳定、维护口碑。
